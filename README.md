## Currency Conversion & Cashout

- **Fixed Valuation**: `2,000 CLOUT = 1 MON = $3.00 USD` (1 CLOUT = 0.0005 MON = $0.0015 USD).
- **Cash out to MON**: Users can exchange CLOUT tokens for native MON directly transferred into their connected Web3 wallet.
- **Claim as MON**: Market winners can claim payouts directly as native MON so funds arrive ready to withdraw.
